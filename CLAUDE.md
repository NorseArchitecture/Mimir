## What This Realm Is

Mímir is **the serving layer** for the platform's reference data — the head Odin carries for counsel, consulted wherever it goes: nobody needs the well itself (Mímisbrunnr) to get an answer. All projects are pure NuGet classlibs — nothing here is a standalone host; everything spins up from Yggdrasil's composition root (declare in a realm, host in Yggdrasil, compose in Bifröst).

| Project | Carries | Rule |
|---|---|---|
| `Reference.Contracts` | The wire records (`CountryRequest` stamped, `CountryResponse` + the `RegionResponse`/`SubregionResponse`/`IntermediateRegionResponse` ancestry), `IReferenceService`, and `ReferencePolicies` (names only) | Thin by law — pure `[DataContract]` shapes in the flat `Norse.Reference` namespace, shared with Mímisbrunnr's baked surface so one `@using` covers both |
| `Reference.Web.Server` | The gRPC `IReferenceService` implementation (handlers over Mímisbrunnr's entities, registration generated by Asgard's `Generator="true"` NorseRef) **and the realm's REST facade** (`CountriesController` : `GrpcControllerBase`) | Server-only; policy names are mirrored onto gRPC methods *and* facade actions for endpoint metadata — registration happens at Yggdrasil's composition root, never here. The facade carries zero wire-format machinery (no STJ/Json.NET — NORSE070); rendering is the host's formatters' job |
| `Reference.Components` | The **headless** shared home (Heimdall's `AuthN.Components` pattern): `CountryRequestValidator`, Blazilla, and any future vendor-neutral machinery | Anything with FluentUI markup belongs in `Reference.Components.FluentUI` instead, never here. NORSE073-governed: consumes foundation and published surfaces only |
| `Reference.Components.FluentUI` | The FluentUI rendering — `CountryLookup` on Asgard's `OutcomeFormComponentBase` | The drop-in vendor pattern: a different design system lands as a sibling, not an edit. Any referencing host discovers routes at compile time (`AddNorseClientComponents()`) — no per-host registration edit exists |
| `.Worker` | Declared, not yet built — the background worker that will keep ISO/IANA data current at runtime | Data freshness is this project's future job, never a release event (see the SemVer contract) |

**Dependency posture:** rides Mímisbrunnr's published surfaces (`Reference.Data.Contracts` via `Reference.Contracts`, `Reference.Data.EntityFramework` from `Reference.Web.Server` only) and Asgard's law; Yggdrasil's hosts ride on *it*, not the other way around. The README's chart draws it; transitive-first holds throughout — the baked browser-safe surface reaches the component pair through `Reference.Contracts`, no direct edge.

**Mímisbrunnr is the companion repository** — one bounded context, two repositories, sharing the `Norse.Reference.*` namespace root deliberately. The split exists for exactly one reason (verified 2026-07-03 against Ginnungagap's `publish-nuget.yml`): release tooling is repo-scoped — a tag packs and publishes a whole repo — and reference-data content churns far faster than serving code. Not the platform's default recommendation; do not copy the split reflexively.

## Architecture Facts (decided — do not re-litigate)

- **The generated surface is authored in Mímisbrunnr, never here.** `IsoCountryCode`, `Iso3166`, and `ReferenceNamespaces` generate in Mímisbrunnr (`Reference.Data.Contracts`/`.Namespaces`) and arrive by reference. Mímir's own generator project and `Reference.Seeds` are gone — moved to Mímisbrunnr; never reintroduce either.
- **`Reference.Data.Contracts` is named for what it is (renamed from `.Data.Primitives`, 2026-08-09).** The rename was forced honestly: NORSE073 struck the first realm Components RCL that consumed it, because "Primitives" classified as neither foundation nor published surface — and collided with the forge's vocabulary word besides. The persistence side publishes *wire-safe contracts*; the dwarves' `Result<T>` still hammers them into values or problems. Do not reintroduce a `Primitives`-named assembly outside Svartálfheim.
- **The component pair is transport-dumb and host-blind.** It injects `IReferenceService`; which implementation stands behind the contract is each host's DI decision. Routes are discovered from the reference closure at compile time — referencing the assembly *is* the registration. `CountryLookup` rides Asgard's `OutcomeFormComponentBase` (hoisted from Heimdall 2026-08-09): forms MUST write `<FormValidator/>` and `OnSubmit` — never `<FluentValidator/>` or `OnValidSubmit` (2026-08-10). `FormValidator` fixes Blazilla's `AsyncMode` on and does not expose it, so no page author decides whether a validator they did not write carries async rules; `SubmitAsync` owns the gate and throws when no `FormValidator` is attached, because a validator-less form validates to `true` with zero messages and looks exactly like a valid one. `OnValidSubmit` would run EditForm's own synchronous pass ahead of that gate and skip async rules. This realm no longer references Blazilla — it arrives transitively through `Abstractions.Components`. Forms MUST also bind `EditContext="EditContextFor(_request)"` (`Model=` binding bypasses the stamped-request blur mechanic and `SubmitAsync` throws on it by design), failure renders through the `ServerValidation` bridge (a field-less problem shows `CategoryDisplay`'s sentence — machinery-owned wording, don't hand-roll messages), and `CountryRequestValidator`'s rules register ON the stamp with `WithName(nameof(CountryRequest.CodeInput))` for display only — `PropertyName` stays `Code`, wire-stable.
- **`Parse` is quad-form, and the fourth form is deliberate:** alpha-2, alpha-3, M49 numeric, or the baked v5 identifier — a `CountryResponse.Id` is legal as the next request's input, and an EF foreign key hydrates the full canon with no join. A well-formed Guid the dataset never minted is `Malformed` like any other unrecognized text.
- **`CountryResponse` digs the whole document, and `Classification` rides as the bare `[Flags]` member** (2026-08-09 amendment to the enum wire law — the channels translate; no interim "kind" enums, no record wrap, no handler mapping). Live today: the gRPC leg's composed varint. **Pending in Midgard before the facade can be host-wired:** the text channels' governed-name array form (JSON converters, XML shape generator) and the deletion of NORSE029, plus the shape generator's closure-walk widening to referenced assemblies — until both land, exposing this response through a shape-generating host strikes the diagnostic/tripwire by design, not by accident.
- **Facade controllers are realm source (2026-08-09 amendment, first consumer here).** `CountriesController` lives beside the service it fronts — never in Yggdrasil, which is a proving ground, not a home. What a realm controller may never do is pull wire-format machinery into the realm (NORSE070's standing jurisdiction). Assigning the route-bound code to `CodeInput` is the text channel's parse event — the same stamp-minting protobuf deserialization performs on the gRPC leg; the facade is a dumb door and passes the verdict through.
- **The interop boundary is Mímisbrunnr's entities and view models, and SemVer there is a pure schema-contract signal:** patch/minor (new rows, non-breaking additions) needs no reaction here; major means the shape changed — the one event that forces this realm to update. Routine data freshness (next tzdata, a new ISO currency) is neither a Mímisbrunnr release nor a Mímir release — it's `Worker`'s future runtime job against the existing schema.
- **Policy names registered at Yggdrasil, never here.** `ReferencePolicies.Public` follows the same law as `AuthNPolicies.Public`: this realm names it and mirrors it onto gRPC methods for endpoint metadata; the composition root registers what satisfies it.
- **This pair is the platform's reference-data template** — Mímisbrunnr proves the substrate needs zero new framework code; Mímir proves the serving layer is three thin projects and a chart.
